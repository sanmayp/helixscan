# H0b: public HG001 Genome in a Bottle truth check

## Result

**HelixScan: 74/75 evaluable, confident autosomal genotypes concordant (98.67%).** 1 genotype(s) are mismatches or no-calls. The independent CIGAR/base allele audit is concordant at 68/75 (90.67%).

All 77 sites were examined. chrX rs1050828 and chrMT rs267606617 are outside the GIAB GRCh38 v4.2.1 1–22 benchmark and are **reported as outside, never counted**. Of the 75 evaluable sites, 22 have a PASS record and 53 have no PASS record within the companion high-confidence BED; only the latter infer homozygous reference. Failed queries cannot become reference calls.

The bounded FASTQ contains 130764 primary, non-duplicate, MQ≥20 alignments. This is public HG001/NA12878 data, not a user's genome. It is a 77-site research check, not clinical validation.

## Methods

1. The shell driver reads `regions.txt`, generated by the Rust tool from `data/panel.json`. Each samtools query has an explicit `chr:start-end`, including one left-anchor base. It excludes UNMAP, SECONDARY, QCFAIL, DUP and SUPPLEMENTARY, retains MQ≥20 alignments, and writes SAM plus FASTQ through samtools in podman. The full FASTQ is scanned with `target/release/helixscan scan --backend cpu`.

2. The Rust checker validates every saved SAM record against its bounds and flags. Exact query-name/flag duplicate records are collapsed for the independent audit. SNVs use the mapped Q≥20 base. Indels reconstruct raw REF/ALT through CIGAR and require two Q≥20 mapped flanking anchors. Unsupported alleles remain `other`, never REF. Genotype multisets compare without allele-order sensitivity.

3. One indexed `bcftools view -H URL chr:position` query per locus provides PASS GT. A successful empty response within the BED infers 0/0. No full VCF is retrieved. Scanner calls are read from the release CLI JSON report; raw counts are independent CIGAR evidence, not k-mer votes.

## Limitations

HG001 contains no panel-indel carrier genotype in the evaluable truth set. Independent indel logic has unit tests; this check does not establish accuracy in an unseen indel carrier or certify phased APOE haplotypes. A bounded locus FASTQ is not a whole-genome sample, so sample-level sex/QC heuristics are not validated by this report.

## Reproduce

From the repository root, with podman and network access:

```sh
scripts/rerun_truth_check.sh
```

The script builds the release scanner and Rust checker, performs 77 bounded public BAM queries and 77 bounded GIAB truth-coordinate queries, scans the resulting FASTQ, checks all 77 genotypes and regenerates this report plus `helixscan-runs/truth-check/results.json`. That directory is gitignored. No private or personal file is used.
